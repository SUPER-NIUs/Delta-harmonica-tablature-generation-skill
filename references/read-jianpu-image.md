# 从图片读简谱：八度点怎么读准（参考）

用户给的常常是**低清截图或拍照**。放大只会更糊，肉眼分辨数字上/下方那个小点已经到极限，
而漏一个点就红底/绿底错一个音。下面是可靠的做法。

## 一、用脚本把「找点」自动化

```bash
python3 scripts/read_jianpu.py 简谱.png -o 工作目录
```

原理（不是 OCR，是像素规律）：

- 数字是 **~18px 高的窄字块**（宽 ≤14px），汉字是 **~22px 高的宽字块**（宽 ≥16px）。
- 八度点是 **4~5px 的小方块**。
- 点只可能落在**「数字行」与相邻「歌词行」之间的那条窄缝**里 ——
  缝里出现的黑块就是点，不会误判成歌词字头。这是关键：把搜索范围限制在那条缝里，
  噪声立刻消失。

脚本输出每行的「槽位序列」：`^` 高音、`v` 低音、`_` 无点，例如

```
数字行 #1  y=23..41  数字 17 个  上点 0 下点 2
  24v  50_  76_  102_ ...  181v  206_ ...
```

即：第 1 个音是低音，第 7 个音是低音，其余中音。

## 二、必须看一眼 overlay.png

脚本会把检测结果画回原图（红圈=检测到的点，蓝线=数字中心，绿线=数字行上下界）。
**红圈错位或漏圈，一眼就能看出来。** 这一步不能省 —— 自动检测会受低对比度点、
粘连字块影响，出错时是安静出错（不报错，只是错了）。

## 三、自动切分不准时，手动指定数字行

脚本自动按行投影切分文字行，排版复杂时会切错。这时自己看行号，用手动模式：

```bash
python3 scripts/read_jianpu.py 简谱.png --bands "24-41,129-146,234-251" --xmax 520
```

`--bands` 是每一条**数字行**的 y 区间；`--xmax` 用于排除图右边缘的装饰花纹。

## 四、最强的自检：交叉验证重复段落

歌曲里同一段旋律会反复出现（主歌两段共用旋律、副歌重复），
**它们的八度点位置必须完全一致**。检测结果如果对得上，基本可以确信读对了。

例：《突然好想你》里
- 「最怕空气突然安静」与「想念如果会有声音」→ 第 1、7 音有低音点，两处一致；
- 「最怕回忆…」与「事到如今…」→ 第 2 音低、第 3、4 音高，两处一致；
- 「听到你的消息」与「还骗不过自己」→ 第 4、5 音低，两处一致。

对不上，就说明哪一段读错了，回去看 overlay。

## 五、还有疑问就定点放大

不要整张放大（那样只会更糊）。**把有疑问的那几个数字单独裁出来放 5~8 倍**
（用最近邻放大，配 `point()` 二值化去背景），一次只看一小块，点、字头、噪声都分得清。

## 六、别做的事

- **不要因为图糊就去搜别的谱源交叉验证。** 读到读不动就按最常见情况处理、交付时说明，
  或直接告诉用户哪一段看不清、请他补一张。多谱源比对是烧 token 的头号坑。
- 不要重复 OCR 或"验证识别结果"。上面这套流程走一遍就够，overlay 看过就算确认。
