# 读简谱时容易漏掉的东西（参考）

用户上传的简谱可能是截图、扫描件、手写、或各种排版风格。逐条核对下面这些记号，
它们是「转出来的谱子弹起来不对」的主要原因。

## 1. 数字本身

- 数字 `1`–`7` 对应 do–si，`0` 是休止符（本 skill 里画成空框，只占歌词位置）。
- 数字的**大小**不代表音高，只有上方/下方的小点才代表八度。

## 2. 八度点（最容易漏）

| 记号 | 名称 | 处理 |
|---|---|---|
| 数字上方一点 | 高音 | 红底，按住右键 |
| 数字上方两点 | 倍高音 | 红底，仅 `^^1` 可行 |
| 数字下方一点 | 低音 | 绿底，按住左键 |
| 数字下方两点 | 倍低音 | 超出音域，需改写 |

## 3. 时长与线条

| 记号 | 名称 | 处理 |
|---|---|---|
| 数字右侧一条横线（`5 -`） | 延音线 / 长音 | 用 `5-`（长按） |
| 数字右下角一个点（`5·`） | 附点，时值 ×1.5 | 用 `5·`（半长按） |
| 数字下方的横线（`5_` 下划线） | 减时线，八分/十六分音符 | 通常忽略，节奏靠歌词字数自然体现 |
| 数字之间的弧线 | 连音线 | 忽略，后一个音不重新起音 |
| 数字上方的 `⌒` 加文字 | 一字多音 | 把多个音符都写出来，歌词只占第一个槽位，其余用 `-` |

## 4. 调号与音阶

- 简谱是**首调唱名法**：不管原曲什么调，`1` 永远是 do。本 skill 直接按数字转键位，**不需要**关心原曲的调。
- 若谱子是「1=C」「1=G」标注的，同样无需转换，这是最关键的一点——不要去做移调。
- 谱面上出现的 `#`、`b` 是临时升降号，按下表处理：`#4`→中键+V，`b7`→中键+M。

## 5. 结构记号

- `‖:` `:‖` 反复号、`D.C.` `D.S.` 反复记号：**展开成线性顺序**再转写；如果太长，只做第一遍并明确告知用户。
- 「第一段/第二段」多段歌词共用同一段旋律：默认只取第一段歌词，或让用户挑一段。
- 前奏、间奏、尾奏：一般只转主歌+副歌的人声旋律，纯器乐段落跳过并说明。
- 转调（谱面中间出现「转 1=D」之类）：仍然按数字照抄，不用管。

## 6. 歌词对齐

- 一个汉字 = 一个音符槽位，绝大多数中文歌都成立。
- 一长串连音（一个字的拖腔）会给多个音符：第一个槽位放歌词，其余写 `-`。
- 英文歌词按单词分槽位。
- 歌词里的标点（逗号、句号）**不要**单独占槽位，直接丢掉。

## 7. 转写完成后自查

对着原谱念一遍：数字个数、歌词个数、每个数字有没有点。
这三样对上了，剩下的就是排版问题，不会弹错音。
