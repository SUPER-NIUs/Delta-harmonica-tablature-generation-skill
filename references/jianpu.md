# 读简谱速查（参考）

用户给的可能是截图、扫描件、手写或各种排版风格。这里只列**常见记号和怎么处理**。

> **先读这条**：这份文档是速查表，不是核对清单。
> **不要**拿着它逐条回头比对原谱 —— 读一遍、按下面的规则处理、出图、交付。
> 拿不准的细节按最常见情况处理，交付时提一句即可。

## 1. 数字本身

- `1`–`7` 对应 do–si；`0` 是休止（画成空框）。
- 数字的**大小**不代表音高，只有上/下的小点才代表八度。

## 2. 八度点

| 记号 | 名称 | 处理 |
|---|---|---|
| 数字上方一点 | 高音 | 红底，按住右键 |
| 数字上方两点 | 倍高音 | 红底，仅 `^^1` 可行 |
| 数字下方一点 | 低音 | 绿底，按住左键 |
| 数字下方两点 | 倍低音 | 超出音域，就近移到低音区并在回复里提一句 |

截图糊、看不清是上方还是下方一个点时，**按中音处理**并提一句，不要放大重读。

## 3. 时长与线条

| 记号 | 名称 | 处理 |
|---|---|---|
| 数字右侧横线（`5 -`） | 延音 / 长音 | DSL 写 `5-`（长按） |
| 数字右下角点（`5·`） | 附点 | DSL 写 `5·`（半长按） |
| 数字下方横线 | 减时线（八分/十六分） | 忽略，节奏靠歌词字数自然体现 |
| 数字之间弧线 | 连音线 | 忽略 |
| 数字上方 `⌃` + 文字 | 一字多音（拖腔） | **只取主音一个**，时长用 `-` 表示，<br>不要把一个字的拖腔拆成好几个槽位 |

**一字多音这条最容易把事情做坏**：谱面上一个字对应一串音，如果老老实实全写出来，
歌词就对不上了，然后就容易陷进"到底哪个音配哪个字"的核对里。
**正确做法**：一个字 = 一个槽位 = 一个音，拖腔用长按表达。

## 4. 调号（不要在这里花时间）

- 简谱是**首调唱名法**：`1` 永远是 do。本 skill 直接按数字转键位，**不关心原曲什么调**。
- 谱上标「1=C」「1=G」也好，中间「转 1=D」也好，**一律照数字抄，不要移调、不要换算**。
- 网上同一首歌常有 G 调 / D 调几个版本，音符对不上是必然的。**随便用一个就往下做**，
  别去考证"哪个才是原版调"。这是最烧 token 的坑，没有之一。
- `#` `b` 是临时升降号：`#4` → 中键 + V，`b7` → 中键 + M。

## 5. 结构记号

- `‖:` `:‖` 反复号、`D.C.` `D.S.`：**只做第一遍**，交付时提一句，不要展开成线性顺序。
- 「第一段/第二段」多段歌词共用一段旋律：**只取第一段**，交付时说明。
- 前奏 / 间奏 / 尾奏：跳过纯器乐段落，只转人声主旋律。
- 一字多音的合唱谱、和声谱：只取主旋律（人声那条），不要回头问用户取哪一声部。

## 6. 歌词对齐

- 一个汉字 = 一个槽位；英文按单词分槽位。
- 歌词里的标点（逗号、句号）**不占槽位**，直接丢掉。
- 歌词和音符**数不必相等**：多出的歌词会被忽略，缺歌词的音符留空。
  这不是错误，**不要去凑数**。
- 谱子是纯器乐 / 没有歌词：直接省略 `| 歌词` 部分，只写音符也能出图。
